## 这是什么

冰点设计系统（@icen.ai/ui）的场景配方技能。当你说"画个图表""接个 AI 聊天""换个主题""装几个组件"时，AI 不用翻文档猜 API——它会按配方直接选对图表类型、五步接完聊天链路、一条命令装对颗粒度。

## 它能做什么

- **图表选型直出**：说清数据形状（时间序列 / 占比 / 对比 / 日历活跃 / 相关性…），AI 直接给出正确的图表类型和一份纯 JSON 配置渲染，悬停、单击、双击、右键、图例眼睛全内置
- **AI 聊天五步接入**：从模型接入到流式输出、工具调用卡、待办状态、用量与审计，一条零接线绑定全部闭环
- **主题与暗色**：六套色彩预设 × 三种风格 × 明暗双模，一句话切换，不写死一个颜色
- **按需安装**：77 个组件按 slug 精确引入（CLI / kit 一行入口 / registry.json），零依赖零框架绑定

## 事实与配方分离

API 的唯一真相在 npm 包内（AGENTS.md + 类型声明），本技能只做"什么时候、走哪条路"的决策，永不与包版本漂移。

## 适合谁

任何项目（原生 / React / Vue / Astro）想用一套克制的、AI 也能直接驾驭的设计系统搭界面的开发者。
