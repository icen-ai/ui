# pref/design 交付报告

2026-10-21。目标见 `MACOS_REDESIGN.md`。按用户最新要求采用成熟桌面控件的比例与交互，不采用 Liquid Glass。修正前提交 `1f0e296` 的审计见 `BRANCH_QUALITY_REVIEW.md`。

## 结果

在已有全 Registry 重构上完成第二轮收口。modern 采用有层次的轮廓：控件 8px，卡片、面板和菜单 14px，弹窗与工作区外壳 20px；微构件 5px，内嵌容器 10px。表格、列表与贴边分区保留直线结构，开关和胶囊保持语义形状。以明度、细边、接触影和间距建立空间，操作面不透明、不模糊。六配色与四原语继续独立，中式、苏式和像素保留自己的身份。

| 范围 | 实际变化 |
| --- | --- |
| 基础与材料 | 统一轮廓阶梯；去除 modern 操作面的模糊，补齐滚动导航状态；保留减少透明与强制颜色路径 |
| 动效 | 修复重复 easing 使浏览器丢弃整条声明；增加 CSS 守卫；验证真实计算时长 |
| 图表 | 环图间隙按弧长封顶，0.5% 和 0.001% 正值仍可见、可交互；图表过渡有效 |
| KB 八份样式 | 固定小字号/高度改用密度角色；嵌套密度重新计算字体；行内操作 normal/compact/comfortable 为 28/24/32px，触摸保留 44px 底线 |
| 加载与 RTL | 加载指示器不再继承透明文字色，居中边距改为逻辑方向 |
| 生命周期 | controls 的类型明确返回销毁函数，与运行时一致；文档换页清理初始化返回的行为监听 |
| 设计工具 | DTCG 解析带单位的有限 calc/min/max/clamp，拒绝未知语法、单位冲突、除零和循环；默认导出排除媒体条件；字号、字重、控件角色正确映射 |
| 全局滚动条 | 原生无箭头皮肤统一；启用行为后默认停滚 900ms 隐藏；auto/scroll/visible/hidden 可局部覆盖，尺寸、颜色、内距、留槽、延时和过渡均可定制。无脚本保持可见，聚焦与强制颜色保留提示；文档侧栏、Inspector 与弹出面板复用 |

变量注释只描述几何、密度、材料与行为。没有新增运行时依赖，没有手改 dist，没有提高预算或降低覆盖率地板。

## 官方文档站与应用组合

- 设置实际切换明暗、系统跟随、密度、动效和滚动偏好，保存到本机，可恢复默认，并尊重系统减少动效。
- 文件实际筛选、分页、查看和选择本机文件；导入明确标为等待业务索引，不伪称已上传或检索完成。
- AI 使用库自身的客户端、流式适配、停止和解绑路径；本地模拟传输不上传消息和附件。权限示例按 query-time pre-filter 过滤，不披露受限资料的存在。
- 数据通过真实 renderChart 更新区间和指标，移除假柱图。
- 手机保留分类与 Inspector；指标两列，数值不再被挤断。
- Inspector 数值由当前 token 计算，切换原语不再显示写死的 6px。站壳使用稳定实面。

首轮全量浏览器测试出现动效测量竞争、诊断截图耗时和负载下的超时。Toast 改为入场动画结束后测量；代码块截图从功能测试迁入独立提交基线；实面断言读取实际 alpha 并等待过渡落定。后续发现命令面板等待动画时会因动画取消而拒绝，改为等待运行中的动画清零。没有提高容差或跳过断言，原始轨迹在本机 `.ui-audit/refinement-first-full-run/` 与 `.ui-audit/command-palette-animation-race/`。

基线以零像素差异阈值重新生成并查看，正常回归仍用原有 1% 阈值。新增应用明暗、RTL、手机、展开弹窗明暗、像素 RTL 代码块基线。清单脚本 `node scripts/design-review.mjs` 的重跑方法见 `docs/testing.md`。

滚动条追加批另覆盖闲置隐藏、默认与显式模式、原生键盘滚动、局部尺寸/留槽、嵌套覆盖、无脚本回退、高对比、减少动效与客户端换页；临时截图在 `.ui-audit/scrollbars/`。轮播缩略图也移除永久隐藏的旧例外，服从同一策略，守卫删除相应豁免。样式策略与留槽独立，默认闲置隐藏只改变滑块颜色，不造成内容宽度跳动。原生颜色过渡由浏览器支持决定，未声称跨浏览器逐帧淡出一致。用法与限制见 [滚动条规格](../spec/scrollbars.md)。

本批全量首轮为 323 通过、1 项主题切换后的对比度采样失败；稳定态扫描改为等待文档时间轴的有限时长过渡结束，排除滚动进度动画，不关闭动效或降低对比度要求。随后应用、滚动条和轮播 12 项专项通过。首轮轨迹保留于 `.ui-audit/scrollbar-theme-transition-race/`，最终完整回归结果见上表。
