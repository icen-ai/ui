# 视觉质量复核

2026-10-21，第二轮精修。交付与工程结果见 `FINAL_REPORT.md`；修正前问题见 `BRANCH_QUALITY_REVIEW.md`。本报告替代此前以自评分判断完成度的版本。

| 发现 | 修正与证据 |
| --- | --- |
| 控件和容器普遍偏直，轮廓相近 | 控件 8、卡片/面板/菜单 14、弹窗/外壳 20px；表格与贴边分区保留结构直线。浏览器验证实际几何与四原语组合 |
| 透明和模糊影响阅读、偏离用户方向 | modern 操作面为实面，弹窗使用 scrim，滚动导航同样不透明；以计算样式和实际 alpha 验证 |
| 静态截图掩盖无效动效 | 修复重复缓动，守卫阻止回归；功能测试验证真实时长，截图只验证静态几何 |
| KB 字号和高度绕过密度 | 八份 CSS 使用密度角色；验证嵌套 compact/comfortable 与自定义 17px 基准 |
| 应用页是假交互 | 设置、文件、AI 流式/停止、图表更新通过独立验收 |
| 手机数值挤断，分类/详情消失 | 指标两列，分类换行，详情移到表格下方；明暗 axe 与页面无横向溢出通过 |
| Inspector 数值与当前原语不符 | 读取真实 token，解析计算尺寸与时长 |
| 滚动条只有皮肤，缺少统一闲置策略；侧栏单独隐藏 | 统一原生无箭头路径，默认停滚后隐藏；四种模式、尺寸、内距、颜色、延时与留槽支持局部定制。专项验证默认/悬停/滚动/聚焦/强制颜色/无脚本/换页，19 张视觉基线刷新后通过 |

`scripts/design-review.mjs` 检查全部 Registry slug 都有文档页，输出包含 git 版本、错误与溢出信息的 manifest。214 张包括：129 个组件首屏、48 张配色、24 张原语、9 张密度、4 张应用。默认保持动效开启，截图时定格；动效由功能测试独立验收。

人工查看了按钮、KB 检索、AI 输入台、桌面/手机应用、明暗弹窗等代表画面，并修正手机指标与分类布局。提交基线位于 `tests/e2e/__screenshots__/visual.pw.ts/chromium/`。

没有用截图数量推导精致度分数，没有将首屏覆盖称为全状态覆盖。完整回归结果以最终报告为准。Windows 字体与光栅化基线仍受环境影响；Safari/Firefox 与实机辅助技术未在本轮认证。

重跑方法见 `docs/testing.md`。构建与巡检必须先后执行，避免产物切换制造无效 404。

滚动条追加批的 19 张基线已重新查看代表画面。上文 214 张清单属于此前精修批；本批全库健康由完整浏览器回归检查展开态、双宽度溢出、axe 与交互，结果见最终报告。
